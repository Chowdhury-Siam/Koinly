Set your administrator password

This page creates the protected value needed for your Worker setup. It runs entirely in your browser and makes no network requests. Keep your chosen password in your password manager.

Use a strong, unique password of 12–256 characters.

Your GitHub secret

In your GitHub repository, open Settings → Secrets and variables → Actions → New repository secret.

For Name, enter ADMIN_PASSWORD_HASH. For Secret, paste the entire value below, then select Add secret.

Select the value and copy it with your browser's usual Copy command. Use your original password when signing in to /profile.
