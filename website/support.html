Support

Answers to common questions about the app and website preview.

Get started offline

Open the installed app, choose Use offline, then select Start New or restore an existing local Koinly backup file. You can create accounts and track transactions without configuring a server.

Use multiple devices

Multi-device synchronization is optional. Deploy your own Cloudflare Worker, connect your own Turso database and sign in with the same Worker and account on both devices. This website's interactive demo cannot sync financial data.

Try the demo

Visit the interactive sample to add transactions, edit category budgets, create plans or notes and explore analytics. The demo uses fictional records, stores changes only in the current browser tab and includes a Reset demo control.

Backups and analytics exports

The installed app supports encrypted local backup files, optional configured delivery and reports in PDF, XLSX and TXT. The browser demo does not download your private records or run Worker backups.
