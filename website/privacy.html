PRIVACY AND DATA PRACTICES

Privacy policy draft

Not ready for store submission. This page is a starting draft based on the current project source. Before making the website public or submitting store listings, the app publisher must verify the actual release build's data flows, hosting practices, service providers, contact details, user rights and retention periods. Remove this warning and the noindex tag only after the policy is finalized.

1. App data stored on your device

Koinly stores financial records such as accounts, transactions, budgets, plans, loans and notes in a local database on the device. The offline experience does not require you to create a Koinly sync account.

2. Optional sync, backups and external services

If you choose to configure synchronization, financial records are transmitted to the server and database you configure, such as your own Cloudflare Worker and Turso database. The app also supports optional backup and report delivery to destinations you configure, including Telegram and Google Drive. The configured third-party services have their own privacy terms and infrastructure.

3. Analytics and crash reports

The Android project currently initializes Firebase and includes Firebase Analytics app-open reporting and Firebase Crashlytics error reporting. The publisher must audit the precise data collected, applicable consent controls, platform differences and third-party retention for the release build. Do not claim the application collects no telemetry without verifying the actual published binary.

4. Website demo

The interactive demo uses fictional accounts and transactions. Changes you make in the demo are stored in this browser tab using sessionStorage. The demo code does not connect to your finances, sync Worker or app account. The website currently includes no third-party analytics scripts; your hosting provider may independently keep ordinary server logs.
